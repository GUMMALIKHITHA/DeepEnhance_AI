# 🚀 DeepEnhance AI

An AI-powered image enhancement web application built using **React.js** and **FastAPI**. The application allows users to upload low-quality images, process them through an AI enhancement pipeline, and download the enhanced results through a modern, responsive interface.

---

## ✨ Features

- 📤 Upload images (JPG, JPEG, PNG)
- 🤖 AI Image Enhancement
- 👀 Image Preview
- 📥 Download Enhanced Image
- ⚡ FastAPI REST API
- 🎨 Modern Responsive UI
- ☁️ Ready for Cloud Deployment

---

## 🚀 Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
